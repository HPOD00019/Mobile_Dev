## 3. Обеспечение тестируемости

Для реализации этих 9 тестов были выполнены следующие архитектурные улучшения:
- **Разгерметизация классов:** Классы переведены из `final class` в `class` для поддержки мокирования (Mockito).
- **Детерминированные ID:** Добавлены методы `restore()` для `OpponentId` и `SessionId`, что позволило использовать фиксированные UUID в тестах вместо случайных.
- **Изоляция:** Все внешние зависимости (репозитории, юзкейсы) полностью изолированы через `Mockito`, что гарантирует скорость выполнения тестов < 5 секунд.
